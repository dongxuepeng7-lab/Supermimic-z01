# Z01 v1.6 全自由度模型

本版本保留 v1.6 下肢，直接移植 `Z01/Z01_dof_27` 的腰、双臂和头部网格、关节及惯性参数。

- 上半身 14 个自由度：腰 2、左右手臂各 5、头部 2。
- 全身 26 个转动关节、27 个连杆。来源目录中的 `dof_27` 并不代表 27 个转动关节。
- MuJoCo 配置 26 个 motor，顺序为原 12 个腿部关节，然后腰、左臂、右臂、头部。
- 原 v1.6 腿部的几何、关节原点、轴、限位、质量和惯性保持不变。

## 入口

- 通用 URDF：`urdf/Z01_v1.6.urdf`
- 带浮动根的 MuJoCo URDF：`mjcf/Z01_v1.6.urdf`
- 带场景、驱动及传感器的 MuJoCo 模型：`mjcf/Z01_v1.6.xml`
- USD：`urdf/Z01_v1.6/Z01_v1.6.usd`

USD 已同步全部上半身关节，保留原来的世界固定根；MuJoCo XML 使用浮动根，`nq=33`、`nv=32`、`nu=26`。

## 安装与惯性来源

旧 Z01 上半身相对 v1.6 基座沿 Z 轴上移 `0.0226525 m`，腰部 yaw 关节的安装高度为 `0.0680237202052 m`。该偏移由新旧腰部网格的对应顶点估计，未经过新版 CAD 轴心数据校准。其他上半身关节的相对原点、转轴、限位、速度及力矩参数沿用旧 Z01。

当前分发包以 `meshes/base_link.STL` 作为骨盆网格，URDF 和 MJCF 均引用该文件；包中没有旧说明提到的 `base_link_articulated.STL`。上半身的 14 个独立 STL 直接复制自旧 Z01；新版双手不包含在本次选用的旧上半身中。

14 个上半身连杆的质量、质心及惯性张量均采用旧 Z01 原值。骨盆采用旧 Z01 基座的质量及关于质心的惯性张量，质心随安装偏移上移至 `(-0.00004133, -0.00000212, -0.04102356) m`。**新版骨盆使用旧版惯性是近似衔接参数，需要新版骨盆质量属性才能精确更新。**

移植后总质量为 `65.46501089 kg`；原 v1.6 合并上身的 `38.30915591 kg` 惯性不再叠加计入。上半身与骨盆碰撞体改为随各连杆运动的局部包围盒，替代原先固定在基座上的整躯干碰撞盒。这些包围盒用于近似碰撞。

## 已完成验证

- 两份 URDF 和 MuJoCo XML 均可由 MuJoCo 加载；关节树连通，网格引用有效。
- 26 个 motor 与关节逐一对应，限位和力矩上限匹配 URDF。
- 12 组姿态下，MuJoCo XML 与浮动根 URDF 的连杆位姿、质心和质量一致。
- 14 个上半身关节分别施加力矩后均产生运动；关闭重力的自由空间 1,000 步数值检查通过。这不是站立控制或实机验证。
- 所有连杆惯性正定，并满足主惯性三角不等式。
- USD 中有 27 个刚体、26 个转动关节；质量、惯性、初始位姿、关节坐标系和限位与 URDF 一致，下肢 USD 配置保持不变。USD 已通过结构检查，未进行 Isaac/PhysX 运行验证。

## PartyMimic 接入

- 浮动根 URDF 中左膝网格引用已修正为随包提供的 `left_knee_pitch_link.STL`。
- 原始 `mjcf/Z01_v1.6.xml` 保留为力矩 motor 的独立场景；训练使用 `../assets/z01/robot.xml`，由 `tools/data/z01_data.py prepare` 生成。
- 训练专用模型使用 PD 位置控制、开启自碰撞、移除自带地面，并排除颈部、腰部近似碰撞盒的两对相邻重叠。
- PD、armature、被动损耗和默认站姿是仿真初始设置，集中在 `../assets/z01/control.json`。它们不是实机标定数据；骨盆惯量近似和上半身安装校准问题仍保留。
- 在 PartyMimic 根目录运行 `uv run python tools/check_z01.py`，检查资产加载、关节顺序、正向运动学、镜像和 5 秒无支撑 PD 站立。
- 完整数据准备、训练和播放命令见 `../assets/z01/README.md`。
