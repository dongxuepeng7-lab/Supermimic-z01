Z01 / SuperMimic 实验代码生成提示词

将「通用任务说明」与下方一个任务一起复制给同一个 AI。P0 先执行，P1 与 P2 可并行。把 P0 生成的仓库路径、提交号、任务入口、张量约定和一条真实运行命令附给后续 AI。不同任务可在独立分支做，直到通过各自验收再合并。不要把整个论文或多项互相依赖的改动一次交给同一个提示词。

通用任务说明

你是负责 Z01 双足机器人 SuperMimic 实验的代码工程师。请在我提供的实际 Z01 项目与指定版本上完成下面一个任务，先检查仓库，再用现有入口实现。公开上游的 G1 项目只能帮助定位接口，不能作为 Z01 的资产、参数、关节顺序、仿真结果或任务 ID。使用仓库现有语言、训练框架与配置习惯。硬件数据只来自已提供的日志，新策略的闭环评估只在物理仿真器完成。不要猜日志字段、参数、实验结果或本机目录。缺输入时要明确报错或产出缺项清单，合成测试数据只能验证代码，并显著标记。正负扰动对必须来源明确，普通真机轨迹不自动组成扰动对。

先检查实际改动处的配置、类型与已有测试。改动尽量小，沿用公共接口并能通过开关禁用新增能力。返回变更文件及用途、实际可运行命令、参数说明、输出目录和验收执行结果，标明实跑与待跑。除了已有测试，按单项验收补最小的防回归检查。把配置、版本、随机种子、数据来源、分割清单摘要、输出字段及单位写进运行清单。避免输出原始真机日志。多任务共用的格式先对照 P0 和上游任务交付物，新增字段须归档到接口表。

实验组约定

A0 用原始标称执行器参数训练原版 SuperMimic，A 用真机辨识参数训练同一算法。两组只替换同一执行器实现中可对照的参数值。两组按种子匹配初始化、域随机化偏移和训练预算，记录限幅后实际参数。两组可分别采集自己的训练轨迹。需要改执行器结构才能接入的参数单独记录与比较。所有策略都在共同的辨识参考工况和留出工况上评估。

A+ 是拥有与 B 相同执行器参数、记忆和目标历史的非结构化世界模型。A+ 和 B 的可训练容量尽量匹配。B 用显式执行器，C 在 B 上增加成对响应损失。B 与 C 共享两条分支的点值拟合、数据、初始化和训练预算。D 和 C-perm 从同一 C 组模型、价值网络与策略检查点分叉，冻结世界模型和价值网络。D 按校准器分配短长窗，C-perm 只重排同一批起点上的窗口标签，保留逐更新的长度直方图。C 的固定窗结果可作参考。

P0｜仓库盘点和最小运行链路

定位实际 Z01 任务注册、资产、参考动作、关节与动作缩放、物理步和控制步、训练入口、独立评估入口、世界模型更新、回放和检查点保存位置。生成 repo_manifest.json 和接口说明，标注上游与 Z01 移植的来源。冻结原始标称执行器配置，记录配置版本、关节映射、单位和校验值。提供一条本地小规模运行命令，完成至少一次真实的世界模型与策略更新，并用无界面评估加载更新后的检查点。记录 GPU、框架版本、吞吐、显存和预热时间。按仓库现有实现确认参考跟踪或独立速度接口。

P1｜真机日志整理、辨识与独立回放

输入我提供的日志样例和关节及单位映射。先按整场试验或 session 划分并冻结 fit/cal/test，再做重采样、对齐、归一化和参数拟合。零值和缺失值分别处理。对 q_cmd、q、dq 和可选电流检查时间戳、方向、单位、覆盖、重置边界和丢帧。保留原始记录，生成 session_split 清单和审计表。只用拟合集估计可辨识的延迟、阻尼或一阶响应，用校准集选择模型，用锁定测试集按原命令和起始状态做开环回放。测试时只用因果预热，禁止用未来测量回填模型状态。输出辨识参数与单位、运行配置、逐试验逐关节误差、1/5/10 步曲线与毫秒对应、有效试验数、排除理由。电流可单列为诊断，未校验换算时保持 A。若日志缺字段或只有一组试验，明确能支持哪些结果，测试指标保留缺测状态。

P2｜可微执行器和回放状态

输入 P0 的接口表和 P1 的已辨识参数。定位动作到目标关节角、仿真执行器和世界模型推进位置。原始物理仿真器中的执行器只作用一次，世界模型内独立表示其响应。显式维护滤波状态 m 和目标延迟队列 b。driver 层在一个策略步内持有目标和策略步起始的 q、dq，沿 driver 时间更新并聚合平均 effort，注明这是近似并对拍真实仿真子步。d=0、重置、限幅、直接响应和跨多步梯度至少做一组确定性测试。回放起点使用已记状态或因果预热，严禁跨 reset 泄漏。提供 A/A+/B 开关。A+ 与 B 接收相同信息和可比可训练参数量，只有作用路径不同。交付配置、运行命令、状态张量接口与仿真对拍误差。用关节输出侧单位区分限幅前请求、限幅后努力与被动阻力。

P3｜仿真正负成对响应生成

从同一物理仿真起点恢复机器人、接触、执行器记忆、域随机化及适用的随机状态，以相同预热历史分别执行 U±εD。记录实际应用的关节目标、ε、方向 D、分支符号、时间、q、dq、接触和限幅标记、pair_id、group_id、split、source。两分支必须来自同一组并且不能跨数据分割。报告正负施加幅度被截断、初始条件不匹配或重置时的处理。提供逐步响应 (y_plus−y_minus)/(2ε)、有效掩码、响应信号底噪与数据覆盖表。模拟标签使用 source=sim，只有已核实的硬件配对记录才用 source=hardware。验收至少对线性小例子核对差分方向和单位，验证相同命令可复现接近零差值，当前平均成本与每步可用深度可追溯。

P4｜响应损失与模型消融

输入 P2 执行器和 P3 成对样本。在同一回放切分、检查点初始化、批次顺序、正负分支点值损失、模型容量和优化预算下训练 B 与 C。C 额外最小化多步方向响应差，B 仅把 λ_R 设为 0。正负分支都从相同初始条件及执行器历史开环滚动。归一化统计只从拟合集得到，记录权重、时间步、掩码和阈值配置。验收 λ_R=0 时等价于 B，合成线性例有预期梯度，缺测掩码或无效 pair 不产生 NaN。输出模型架构与参数数、检查点、1/5/10 步及逐前缀的拟合和验证误差、锁定测试入口。真机配对扩展常规日志不足时关闭，备选实验用仿真对且标签可追溯。

P5｜窗口校准和等预算消融

从 C 检查点分叉，固定世界模型和同一价值网络。使用独立校准分割，锁定短窗、长窗、分箱规则、独立 block 最小数、信号底噪、误差分位数和容差。长窗所需的逐步前缀必须实际存在。短窗覆盖已观察到的执行器响应起点。覆盖不足或超差时回退短窗并记录未验证标记。在共同 rollout-start 批次上计算 D 的窗口标签，用可复现置换得到 C-perm，逐更新精确保持标签计数、起点批次和有效想象步总数。两个分支使用同一终止处理、价值边界、优化更新次数与冻结初始化。记录 padding 后实际计算步数、批量大小和墙钟，不将梯度掩码当成实测加速。交付校准文件、逐更新账本和评估检查点。验收检查 test 拒绝输入、短长窗覆盖、每次更新直方图一致、梯度有限且可复现。若校准总是回退同一窗口，报告退化，不补造判别效果。

P6｜批量训练、预算和断点恢复

以 P0 的入口接入 A0/A/A+/B/C 及 P5 的分叉实验。为 A0/A 设置两个显式训练参数配置，按关节匹配字段和单位。输出配置差异及每个随机样本实际生效的参数，核对只有约定的执行器值发生变化。两组共享模型、算法、初始化种子、随机化偏移分布、训练步数、更新预算、检查点和评估频率。新增执行器结构另立实验。给每次运行唯一 run_id 并记录 group、training_seed、训练参数配置、硬件、精度、配置校验值、优化更新数、物理仿真步数、想象步数、实际计算步数、分阶段耗时及检查点。用先导吞吐安排 4090/5080，同种子计时对照放同型号卡。提供 dry-run、断点恢复和小规模验收，检查日志完整及计数单调。

P7｜预测稳定性、响应鲁棒性与闭环仿真

实现三个共用 P0/P1 数据接口的评估入口。其一，从留出轨迹和因果预热初始化，输入原始记录指令并连续开环预测。在第 1、5、10 步和实际反传窗口内输出逐步关节角和角速度 RMSE 及有效数，步长同时用毫秒报告。记录超预设容差、非有限值、参考提前结束和缺测四种状态。用相同的会话、初始状态与指令比较原始标称和辨识参数的物理回放。仅能重建单关节时限定在对应通道。真机日志未提供时保留缺测。

其二，复用 P3 的锁定仿真扰动对。按未参与拟合和窗口校准的幅度区间或参数组合，比较响应方向、幅度与起始时间。信号低于校准底噪时标注，并按步长、关节、工况输出误差和有效配对数。真机方向响应只用经核实的正负配对记录。

其三，给所有策略统一加载一份物理仿真测试场景清单。A0、A 及其余组对每个场景使用相同参数、初态、指令和测试种子。设置共同辨识参考工况和预先留出工况。选延迟、阻尼或限幅的可配置组合，记录留出规则与训练分布。输出 episode 完成、提前终止、有效时长、速度 RMSE 与 test_scenario_id。验收包含故意提前终止、开环非有限输出、缺日志及 A0/A 场景清单一致的检查。结果保留 source、split、seed 和 run_id。

P8｜统计、论文图表和复核

从 P4–P7 读取真实输出，按 training_seed 与 test_scenario_id 配对 A0/A。对共同参考与留出工况分别报告每个种子的完成率增益（A 减 A0，百分点）和速度 RMSE 降幅（A0 减 A，m/s），附种子间不确定性、有效种子数及分母。保留每个策略从参考到留出工况的性能变化。真机开环的原始标称/辨识差按会话配对汇总。输出 A+/B、B/C、C-perm/D 消融，绘制开环误差随步长、仿真成对响应和闭环训练曲线。仅使用同型号 GPU 的记录做耗时配对。未达标运行标记为删失，缺测保留状态。提交可复现命令、带单位 CSV、矢量图和填稿索引。用小例子核对增益符号、配对、分母和缺测处理，单列合成测试产物。
